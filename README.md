# Eden NX2 — Official Windows Release Channel

This public repository hosts **tested, approved Windows emulator release downloads** built from the private Eden NX2 development repository.

## Download and update
When the first release is ready, visit [Releases](https://github.com/leepeterss85-hue/NX2-release/releases). Expected assets:
- `eden-nx2-windows-x64.zip` — portable Windows program
- `eden-nx2-windows-x64.zip.sha256` — SHA-256 checksum

The Eden NX2 updater uses this public repository's Releases channel to check for new `passNNN` versions. Users should use **Check for Updates** inside a compatible Eden NX2 build. Older builds may need a one-time installation of a version configured for this channel.

## Safety
A successful GitHub build does not imply compatibility with every game or device. Releases should be published only after Windows startup, gameplay, audio/video, update and rollback checks. No games, firmware, encryption keys, personal profiles, save files, or private source-code credentials are distributed here.
